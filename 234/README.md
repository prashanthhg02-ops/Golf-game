# Little Links

A small, self-contained mini-golf game built with HTML, CSS, and JavaScript. No dependencies or build step are required.

## Play

Open `index.html` in a modern web browser.

## How to play

- Drag back from the golf ball to aim and choose shot power.
- Release to putt.
- Avoid the water; each splash adds a one-stroke penalty.
- Sink the ball, then choose **Next hole** to continue the three-hole round.
- Use **Restart hole** to replay the current course.

The game supports mouse and touch input and includes stroke/par scoring, sand that slows the ball, and course obstacles.
